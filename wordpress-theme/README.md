## 🚀 خطوات التثبيت (للمطور)

### الخطوة ١: تثبيت WordPress
1. حمّل WordPress من [wordpress.org](https://wordpress.org/download/)
2. ارفع الملفات على الاستضافة
3. أنشئ قاعدة بيانات MySQL
4. اتبع معالج التثبيت

### الخطوة ٢: رفع الثيم
1. اضغط على مجلد `wordpress-theme/` وأعده تسمية إلى `anthro`
2. ارفعه إلى: `wp-content/themes/anthro/`
3. **أو** اضغطه كـ ZIP وارفعه من: لوحة التحكم → المظاهر → رفع مظهر

### الخطوة ٣: تفعيل الثيم
- لوحة التحكم → المظاهر → أنثرو → تفعيل

### الخطوة ٤: الإعدادات الأولية
```
الإعدادات ← أولية
  ├── حدد: "قراءة" → "صفحة ثابتة" → الصفحة الرئيسية
  └── أنشئ صفحة اسمها "الرئيسية" وحددها

الإعدادات ← روابط دائمة
  └── اختر: "اسم المنشور" /post-name/
```

## 🎛 لوحة التحكم — دليل العميل

### نشر مقال جديد
1. **المقالات** ← **جديد**
2. أكتب العنوان والمحتوى
3. في "⚙️ إعدادات المقال":
   - ✅ ضع وقت القراءة (مثال: 8)
   - ✅ اكتب الاقتباس الافتتاحي
   - ✅ اختر "⭐ مقال مميز" ليظهر في الهيرو
4. في "التصنيفات": اختر تصنيف المقال
5. في "الصورة المميزة": ارفع صورة المقال
6. اضغط **نشر** ✅

### نشر حلقة بودكاست جديدة
1. **🎙 البودكاست** ← **جديد**
2. أكتب العنوان ووصف الحلقة
3. في "🎙 معلومات الحلقة":
   - رابط الصوت (MP3 أو SoundCloud)
   - رقم الحلقة (مثال: 8)
   - مدة الحلقة (مثال: 52:30)
   - اسم الضيف
   - روابط Spotify / Apple
4. في "المواسم": اختر الموسم أو أضف جديداً
5. اضغط **نشر** ✅

### إضافة كاتب جديد
1. **المستخدمون** ← **جديد**
2. أكمل البيانات (اسم، بريد، كلمة مرور)
3. الدور: **محرر** (يستطيع نشر مقالات)
4. أكمل الملف الشخصي (لافتة، وصف، رابط تويتر)

## 🎨 تخصيص الهوية البصرية

**المظهر** ← **التخصيص** ← **🌿 إعدادات أنثرو**

| القسم | ماذا تخصص |
|---|---|
| **الألوان** | اللون الزيتوني، النحاسي، الخلفية، الداكن |
| **وسائل التواصل** | روابط تويتر، إنستقرام، سبوتيفاي، Apple |
| **الصفحة الرئيسية** | عنوان الهيرو، عدد المقالات في الصفحة |
| **الفوتر** | نص الحقوق |

**الشعار:** المظهر ← التخصيص ← هوية الموقع ← الشعار

## 🔧 بنية Custom Post Types

### `podcast_episode` — حلقة البودكاست
| حقل Meta | المعنى | مثال |
|---|---|---|
| `_anthro_audio_url` | رابط ملف الصوت | https://... |
| `_anthro_ep_number` | رقم الحلقة | 8 |
| `_anthro_ep_duration` | مدة الحلقة | 52:30 |
| `_anthro_guest_name` | اسم الضيف | د. نورة المحمد |
| `_anthro_spotify_url` | رابط سبوتيفاي | https://... |
| `_anthro_apple_url` | رابط Apple Podcasts | https://... |

### `post` — المقال
| حقل Meta | المعنى | مثال |
|---|---|---|
| `_anthro_featured` | مقال مميز | 1 أو 0 |
| `_anthro_read_time` | وقت القراءة (دقائق) | 8 |
| `_anthro_opening_quote` | الاقتباس الافتتاحي | نص الاقتباس |

## 🌐 إعداد ثنائية اللغة (اختياري)

إذا أردت الموقع بالعربية والإنجليزية:
1. ثبّت **WPML** أو **Polylang**
2. أضف اللغة الإنجليزية
3. ترجم كل مقال/صفحة منفصلاً
4. الثيم يدعم RTL/LTR تلقائياً حسب لغة الصفحة
